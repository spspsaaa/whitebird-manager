# WhiteBird Manager: локальное расширение (тест)

Это **не** автоматический парсер WhiteBird и **не** интеграция с Telegram. Расширение считывает **только текст, который пользователь сам выделил** на текущей HTTPS-странице после нажатия кнопки. Нет фоновых запросов, доступа к cookies, паролям или 2FA, хранения данных или финансовых операций.

## Установка без Python

1. Скачай проект GitHub как ZIP и распакуй.
2. Открой существующий профиль Octo Browser.
3. Открой страницу управления расширениями (обычно `chrome://extensions`; доступность зависит от версии Octo).
4. Включи режим разработчика, затем «Загрузить распакованное расширение» и выбери папку `safe-demo/whitebird-readonly-extension`.
5. Открой WhiteBird в этом профиле, войди обычным способом и убедись, что баланс виден.
6. Выдели мышкой **только значение баланса** (не пароли или коды), нажми значок расширения и кнопку «Прочитать выделенное».

Если расширения запрещены политикой браузера, не пытайся обходить ограничение.

## Ограничения

Текущая версия показывает выделенный текст в окне расширения и ничего не отправляет в Telegram. Для автоматического определения RUB/USDT нужно исследовать структуру страницы на тестовом аккаунте, не передавая чувствительные данные. Не пытайся скрывать автоматизацию или обходить проверки WhiteBird.
