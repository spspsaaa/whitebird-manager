# WhiteBird Manager — локальное чтение RUB.wb и USDT

**Версия 0.2 (экспериментальная).** Работает только на HTTPS-домене `whitebird.io` после явного нажатия кнопки расширения. Пытается прочитать видимые строки RUB.wb и USDT в таблице кошельков. Не нажимает кнопки, не меняет прокси/отпечаток/cookies, не получает пароли/2FA и не отправляет баланс в Telegram или сеть.

## Обновление установленного расширения

1. Скачай свежий ZIP ветки `feature/secure-auth-approval` и распакуй его.
2. В уже открытом профиле Octo зайди на `chrome://extensions`.
3. Удали **старую тестовую копию** расширения (не сам профиль Octo).
4. Нажми «Загрузить распакованное расширение» и выбери папку `safe-demo/whitebird-readonly-extension` из нового ZIP.
5. Открой `https://whitebird.io/account/wallets?category=ALL`, войди в WhiteBird обычным способом и сделай баланс видимым.
6. Нажми расширение → «Считать RUB.wb и USDT».

Если показывает «не найдено», это не нулевой баланс: DOM сайта может отличаться. Не присылай пароль, коды или cookies. Можно сообщить только, какие поля найдены.

**Ограничение:** распознавание основано на предполагаемом порядке видимых столбцов (валюта, стоимость, баланс, эквивалент). До проверки на реальной странице суммы нельзя считать подтверждёнными. Не выполняет финансовых операций.
