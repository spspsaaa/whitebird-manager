# Запуск двойным щелчком (Windows)

1. Открой папку `safe-demo` на своём компьютере.
2. Дважды нажми `START_LOCAL_TEST.bat`.
3. Откроется окно проверки. В конце оно останется открытым, чтобы можно было прочитать результат.

Если Windows сообщает, что Python не найден, его нужно установить с официального python.org. Не вводи пароли, коды 2FA или данные WhiteBird в это окно.

**Что делает файл:** запускает только офлайн-тесты демонстрационного кода. Он **не** подключается к Telegram, не запускает Octo/Dolphin и **не** читает реальный баланс WhiteBird. Интеграция с реальными браузерами пока не реализована; для неё потребуется отдельная проверка поддерживаемого интерфейса браузера и безопасной авторизации.
