# Whitebird Manager

Telegram-менеджер аккаунтов Whitebird: балансы, вывод средств, авто-вывод по порогу,
конвертация фиата в крипту и импорт сессии из антидетект-браузера.

## Возможности

- **Мультиаккаунтность** — каждый аккаунт со своими логином, паролем, 2FA-ключом,
  кошельком, валютой и сетевой настройками. Настройки одного аккаунта не влияют
  на остальные, сессии изолированы (отдельный файл токенов на аккаунт).
- **Балансы** — с USD-эквивалентом, по всем аккаунтам или по одному.
- **Вывод средств** — расчёт комиссии, подтверждение владельцем, исполнение.
- **Массовый вывод** — запуск по всем аккаунтам с индивидуальными параметрами.
- **Автоматический вывод** — порог на аккаунт, проверка по расписанию, уведомление.
- **Конвертация RUB -> крипта** — котировка, создание ордера, ожидание результата.
- **Импорт сессии из антидетект-браузера** — Dolphin Anty и Octo Browser.

## Антидетект-браузеры

Браузер нужен **только чтобы получить сессию** (вход, смена пароля, настройка 2FA).
Сессия Whitebird — это OAuth-токены (`access_token` / `refresh_token` / `expires_at`),
а не cookies, поэтому после импорта браузер больше не нужен: `refresh_token`
продлевает доступ сам.

| Браузер | Локальный API | Запуск профиля |
|---|---|---|
| Dolphin Anty | `localhost:3001` | `GET /v1.0/browser_profiles/{id}/start?automation=1` |
| Octo Browser | `localhost:58888` | `POST /api/profiles/start` `{"uuid": ..., "debug_port": true}` |

Локальные API слушают только `127.0.0.1` — backend должен быть на той же машине
(или рядом с VPN/туннелем до неё). Сессия читается напрямую по CDP
(WebSocket), без запуска полноценного браузера на сервере — Chromium не
нужен, достаточно websocket-эндпоинта, который возвращает локальный API
антидетект-браузера.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить
python -m app.main
```

## Настройка

Переменные окружения (см. `.env.example`):

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен Telegram-бота |
| `OWNER_ID` | ваш Telegram ID — доступ к боту имеют только вы |
| `ENCRYPTION_KEY` | Fernet-ключ для шифрования паролей и 2FA-ключей |
| `DATABASE_URL` | путь к БД |
| `TOKEN_STORE_DIR` | каталог с файлами сессий |
| `BALANCE_POLL_SECONDS` | период проверки порогов авто-вывода |

Сгенерировать ключ:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## Безопасность

- Доступ к боту проверяется **на сервере**: сообщения от посторонних игнорируются
  молча — ни ответа, ни утечки данных.
- Пароли, 2FA-ключи и токены шифруются Fernet-ключом при хранении.
- Перед выводом средств требуется подтверждение владельцем.
- Ошибки антифрода Whitebird не обходятся: операция останавливается с просьбой
  завершить проверку в браузере.

## Структура

```
app/
  main.py              точка входа: бот + планировщик + /health
  config.py            настройки из окружения
  security.py          шифрование и проверка владельца
  db.py / models.py    БД и модели
  account_manager.py   CRUD аккаунтов и индивидуальные настройки
  auto_withdrawal.py   проверка порогов и авто-вывод
  services.py          связка БД, аккаунтов и API
  wb/                  работа с Whitebird API
    browsers/          адаптеры Dolphin Anty и Octo Browser
    auth.py balance.py withdrawal.py exchange.py
  bot/                 хендлеры, клавиатуры, контроль доступа
```
